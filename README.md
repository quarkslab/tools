
# Quarkslab Open Source Tools

Most of our open source tools are published under https://github.com/quarkslab but not all,
so here is a more exhaustive list.

* [pixiefail](https://github.com/quarkslab/pixiefail): PoC for PixieFail vulnerabilities
* [dxfx](https://github.com/quarkslab/dxfx): DxFx is a proof-of-concept DJI Pilot unpacker
* [diffing_obfuscation_dataset](https://github.com/quarkslab/diffing_obfuscation_dataset): The dataset was used as a support to attack obfuscations. It is the largest obfuscated dataset, with realistic and various binaries and functions. It is made to support other experiments on obfuscation for research purposes
* [sstic-tame-the-qemu](https://github.com/quarkslab/sstic-tame-the-qemu): QEMU support for a custom board based on a Microchip ATSAMD21G18A microcontroller (MCU)
* [samsung-bootchain-poc](https://github.com/quarkslab/samsung-bootchain-poc): PoC associated to the talk "Attacking Samsung Galaxy A* Boot Chain" (https://www.blackhat.com/us-24/briefings/schedule/#attacking-samsung-galaxy-a-boot-chain-and-beyond-38526)
* [ble-gatt-fuzzing](https://github.com/quarkslab/ble-gatt-fuzzing): Tool developed to fuzz the GATT layer of the Bluetooth Low Energy protocol based on defined attack scenarios.
* [nvidia-ngx-wrapper](https://github.com/quarkslab/nvidia-ngx-wrapper)
* [can-workshop](https://github.com/quarkslab/can-workshop): Files for the Grehack 2021 workshop: Revers3 me if you CAN
* [qbindiff](https://github.com/quarkslab/qbindiff): Quarkslab Bindiffer but not only !
* [ziphyr](https://github.com/quarkslab/ziphyr): On-the-fly zip of streamed file with optional zipcrypto.
* [BVWhiteBox](https://github.com/quarkslab/BVWhiteBox): This PoC illustrates our work on asymmetric white-box cryptography, it can be used to generate a set of lookup tables used for lattice-based white-box scheme
* [Diffing Portal](https://diffing.quarkslab.com/): various resources on binary diffing
* [Crypto-condor](https://github.com/quarkslab/crypto-condor): a test suite for cryptographic primitives, including Qb version of TestU01-2009
* [Prism](https://github.com/quarkslab/erlang-prism): a light BEAM disassembler for Erlang
* [Numbat](https://github.com/quarkslab/numbat): Library to manipulate and create Sourcetrail databases
* [NumbatUI](https://github.com/quarkslab/NumbatUI): a fork of Sourcetrail
* [LIEF](https://lief.quarkslab.com/): a cross-platform library for parsing, modifying and abstracting ELF, PE and MachO executable formats
* [QBDI](https://qbdi.quarkslab.com/): a modular, cross-platform, cross-architecture binary dynamic instrumentation framework
* [Triton](https://triton.quarkslab.com/): a symbolic execution library
* [Qsynthesis](https://github.com/quarkslab/qsynthesis): an API in Python3 for performing I/O-based bit vector expression program synthesis
* [QBDL](https://github.com/quarkslab/qbdl): QuarkslaB Dynamic Linker is a library for dynamically loading and linking binaries in a modular and portable way
* [AERoot](https://github.com/quarkslab/aeroot): a tool that allows to grant on the fly root rights to any process running in the Android emulator with Android Virtual Devices labeled Google Play
* [Mattermost e2ee](https://github.com/quarkslab/mattermost-plugin-e2ee): a plugin for the Mattermost chat application to implement end-to-end encrypted communications
* [Rewind](https://github.com/quarkslab/rewind): a snapshot-based coverage-guided fuzzer targeting Windows kernel components
* [whvp](https://github.com/quarkslab/whvp): a PoC for a snapshot-based coverage-guided fuzzer targeting Windows kernel components (now replaced by Rewind)
* [kdigger](https://github.com/quarkslab/kdigger): a context discovery tool for Kubernetes penetration testing
* [minik8s-ctf](https://github.com/quarkslab/minik8s-ctf): a beginner-friendly CTF about Kubernetes security
* [Bgraph](https://github.com/quarkslab/bgraph): a tool to generate dependency graphs from Android.bp soong files
* [windbg-vtl](https://github.com/quarkslab/windbg-vtl): a JavaScript debugger extension for WinDbg that allows to dump the partitions running on Hyper-V
* [Windefender Network Inspection tools](https://github.com/quarkslab/wdnis_tool): WindTalker is a tool for interacting with the Windefender network inspection's driver
* [BVWhitebox](https://github.com/quarkslab/BVwhitebox): proposal for an asymmetric lattice-based white-box scheme presented in https://eprint.iacr.org/2020/893
* [titanm](https://github.com/quarkslab/titanm): various reverse engineering and vulnerability research tools developed for our research on the Titan-M chip
* [Arybo](https://github.com/quarkslab/arybo): a software for manipulating such expressions using bit vectors and gives a bit-per-bit symbolic representation
* [Binbloom](https://github.com/quarkslab/binbloom): a raw binary firmware analysis software
* [AOSP Dataset](https://github.com/quarkslab/aosp_dataset): a large commit precise vulnerability dataset based on AOSP CVE
* [Quokka](https://github.com/quarkslab/quokka): a fast and accurate binary explorer
* [Qsig](https://github.com/quarkslab/qsig): a patch signature generation-detection tool
* [TPMee](https://github.com/quarkslab/tpmee): TPMee stands for TPMEavesEmu. It help to exploit weak implementations of library or program that used TPM
* [Peetch](https://github.com/quarkslab/peetch): a collection of tools aimed at experimenting with different aspects of eBPF to bypass TLS protocol protections
* [idascript](https://github.com/quarkslab/idascript): a collection of utilities scripts and Python module to facilitate executing idapython scripts in IDA
* [PASTIS](https://github.com/quarkslab/pastis): a collaborative fuzzing framework
* [Pyrrha](https://github.com/quarkslab/pyrrha): a tool to do firmware cartography
* [python-bindiff](https://github.com/quarkslab/python-bindiff): a friendly interface to launch and manipulate bindiff between two binary files
* [python-binexport](https://github.com/quarkslab/python-binexport): a Python interface for Binexport, the Bindiff export format
* [TritonDSE](https://github.com/quarkslab/tritondse): a Triton-based DSE library with loading and exploration capabilities
* [android-fuzzing](https://github.com/quarkslab/android-fuzzing): a tool to perform Android greybox fuzzing with AFL++ Frida mode. It contains the material associated with the blogpost Android greybox fuzzing with AFL++ Frida mode
* [hooking-golang-playground](https://github.com/quarkslab/hooking-golang-playground): a tool to conduct various experiments with golang internals. Companion code used for the blog post “Let's Go into the rabbit hole (part 1) — the challenges of dynamically hooking Golang programs”
* [starlink-tools](https://github.com/quarkslab/starlink-tools): a collection of tools for security research on Starlink's User Terminal
* [wirego](https://github.com/quarkslab/wirego): a Wireshark plugin wrapper for golang
* [PQC_tables](https://github.com/quarkslab/pqc_tables): the project summarizes the current ANSSI views regarding post-quantum cryptography scheme usages for (French) certifications
* [LLDBagility](https://github.com/quarkslab/LLDBagility): a tool for macOS kernel debugging that allows to connect LLDB to any macOS virtual machine running on a patched version of the VirtualBox hypervisor
* [IRMA](https://github.com/quarkslab/irma/): an asynchronous and customizable analysis system for suspicious files
* [Binmap](https://github.com/quarkslab/binmap): a system scanner, looking for programs and libraries and collecting various information such as dependencies, symbols etc
* [SSPAM](https://github.com/quarkslab/sspam): a software for simplifying mixed expressions (expressions using both arithmetic and boolean operators) with pattern matching
* [quarkspwdump](https://github.com/quarkslab/quarkspwdump): Dump various types of Windows credentials without injecting in any process.
* [dreamboot](https://github.com/quarkslab/dreamboot): UEFI bootkit
* [qb-sync](https://github.com/quarkslab/qb-sync): qb-sync is an open source tool to add some helpful glue between IDA Pro and Windbg. Its core feature is to dynamically synchronize IDA's graph windows with Windbg's position. 
* [libleeloo](https://github.com/quarkslab/libleeloo): Library to manage big sets of integers (and IPv4 ranges)
* [iMITMProtect](https://github.com/quarkslab/iMITMProtect): Prevent Apple to mess with keys
* [linksys-wag200G](https://github.com/quarkslab/linksys-wag200G): Some binaries and tools for the Linksys WAG200N router
* [irma-brain](https://github.com/quarkslab/irma-brain): IRMA brain
* [irma-frontend](https://github.com/quarkslab/irma-frontend): IRMA frontend
* [irma-probe](https://github.com/quarkslab/irma-probe): IRMA probe
* [irma-common](https://github.com/quarkslab/irma-common): IRMA common
* [land_of_cxx](https://github.com/quarkslab/land_of_cxx)
* [ip_conv_sse](https://github.com/quarkslab/ip_conv_sse)
* [nodescan](https://github.com/quarkslab/nodescan): Asynchronous scanning library
* [irma-ansible-old](https://github.com/quarkslab/irma-ansible-old): IRMA ansible
* [irma](https://github.com/quarkslab/irma): IRMA is an asynchronous & customizable analysis system for suspicious files.
* [irma-probe-tutorial](https://github.com/quarkslab/irma-probe-tutorial)
* [irma-formatter-tutorial](https://github.com/quarkslab/irma-formatter-tutorial)
* [llvm-dev-meeting-tutorial-2015](https://github.com/quarkslab/llvm-dev-meeting-tutorial-2015): Material for an LLVM Tutorial presented at LLVM Dev Meeting 2015
* [irmacl](https://github.com/quarkslab/irmacl): irma api command line client
* [NFLlib](https://github.com/quarkslab/NFLlib): NTT-based Fast Lattice library
* [irma-web-ui](https://github.com/quarkslab/irma-web-ui): IRMA Web User Interface
* [dataset-call-graph-blogpost-material](https://github.com/quarkslab/dataset-call-graph-blogpost-material)
* [sboot-binwalk](https://github.com/quarkslab/sboot-binwalk)
* [irma-ansible](https://github.com/quarkslab/irma-ansible)
* [irmacl-async](https://github.com/quarkslab/irmacl-async): Asynchronous client library for IRMA API
* [android-restriction-bypass](https://github.com/quarkslab/android-restriction-bypass): PoC to bypass Android restrictions
* [training_ecu](https://github.com/quarkslab/training_ecu): Hardware and software for the ECU we use during trainings
* [samsung-trustzone-research](https://github.com/quarkslab/samsung-trustzone-research): Reverse-engineering tools and exploits for Samsung's implementation of TrustZone
* [legu_unpacker_2019](https://github.com/quarkslab/legu_unpacker_2019): Scripts to unpack APK protected by Legu
* [qb.backup](https://github.com/quarkslab/qb.backup): The server-side script of the qb.backup orchestration solution.
* [ansible-role-qb.backup](https://github.com/quarkslab/ansible-role-qb.backup): The Ansible role setting up Debian servers that need to be backuped by qb.backup.
* [ansible-role-qb.backup_server](https://github.com/quarkslab/ansible-role-qb.backup_server): The Ansible role setting up a FreeBSD Jail running the script qb.backup.
* [ansible-playbook-qb.backup](https://github.com/quarkslab/ansible-playbook-qb.backup): An example Ansible playbook deploying the roles qb.backup and qb.backup_server.
* [CVE-2020-0069_poc](https://github.com/quarkslab/CVE-2020-0069_poc)
